# Persist one conversation for a guest

Chat0 gives each issued anonymous identity one guest allowance and stores its conversation in Convex. The conversation survives refresh in the same browser and transfers into permanent history on sign-in; browser clearing can create another identity, so network, bot, principal, and global budget controls contain abuse without claiming to identify a human permanently.

V1 does not expire inactive guest conversations automatically. Retention cleanup remains a post-v1 discussion.
